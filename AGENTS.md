# AGENTS.md — Sellio project

## Repository purpose

Self-managed rebuild of the Sellio PWA (originally built in Lovable Cloud). All code
lives here; no shared state with the Lovable project. Design spec:
[`docs/superpowers/specs/2026-08-06-sellio-rebuild-design.md`](docs/superpowers/specs/2026-08-06-sellio-rebuild-design.md).

## Stack

- TanStack Start v1 (React 19, Vite 8, TanStack Router, TanStack Query)
- Tailwind CSS v4 + shadcn new-york primitives + Midnight Plum tokens (src/styles.css)
- Supabase (Postgres, Auth, Storage, Realtime) — free project, runs in the cloud
- NVIDIA NIM for AI (`@ai-sdk/openai-compatible` against `https://integrate.api.nvidia.com/v1`)
- Bun as the package manager + script runner (npm also works)

## Key conventions

- **Never edit** `src/routeTree.gen.ts` — generated by the TanStack Router plugin.
- **Never edit** `src/integrations/supabase/types.ts` by hand — regen with
  `supabase gen types typescript --linked`.
- Migrations in `supabase/migrations/` are the source of truth for schema/RLS.
- Auth boundary: client `attachSupabaseAuth` (functionMiddleware in `src/start.ts`) →
  server `requireSupabaseAuth` middleware (per server-fn). Only the 5 AI fns in
  `src/lib/ai.functions.ts` opt into the server middleware today; route loaders
  rely on the `_authenticated/route.tsx` `beforeLoad` gate + RLS.
- AI keys never ship to the browser. All AI calls go through `createServerFn`
  with `.middleware([requireSupabaseAuth])`. If you find a route doing a raw
  `fetch` to NVIDIA, refactor it into a server fn.
- Per-function AI model ids live in `src/lib/models.server.ts` — one constant
  per server fn. Swap a model by editing one line.
- Agentic changes belong in commits scoped to a single phase from the design spec.

## File-map quick reference

- `supabase/migrations/` — 8 SQL migrations (verbatim from the Lovable export)
- `src/integrations/supabase/` — generated clients + types + `requireSupabaseAuth` middleware
- `src/integrations/lovable/index.ts` — OAuth helper (rewired to `supabase.auth.signInWithOAuth`)
- `src/lib/ai-gateway.server.ts` — NVIDIA NIM provider factory
- `src/lib/ai.functions.ts` — the 5 AI server fns (authenticated)
- `src/lib/models.server.ts` — per-function AI model registry
- `src/lib/cart-store.ts` — localStorage cart (`sellio.cart.v1`)
- `src/components/ui/*` — shadcn primitives (do not hand-edit unless extending)
- `src/routes/` — 28 TanStack Router file-based routes

## Running locally

```bash
bun install
cp .env.example .env       # fill in Supabase + NVIDIA keys
bun run dev                # http://localhost:3000
```

`bun run build` and `bun run lint` should always exit 0 before a commit.
